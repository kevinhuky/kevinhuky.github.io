## 为什么写博客

写博客主要是为了逼自己学习。

很多东西看过就忘，但如果要写出来给别人看，就得真正搞懂。输出倒逼输入，这招对我挺有效的。

另外，也想记录一下自己的成长轨迹。几年后回头看，应该会挺有意思的。
